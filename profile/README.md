# Ali-Sample

A learning sandbox for running an ERPNext-based system on GitHub: org settings, teams, rulesets,
environments, CI/CD and configuration as code.

**Placeholder data only.** No real company data, secrets or customer records belong here.

| Repo | What it holds |
|---|---|
| [`.github`](https://github.com/Ali-Sample/.github) | Org profile, default templates and policies |
| [`org-config`](https://github.com/Ali-Sample/org-config) | GitHub org configuration as code (Terraform) |
| [`erpnext-local`](https://github.com/Ali-Sample/erpnext-local) | Local ERPNext with frappe_docker, versions pinned |

Work is tracked on the [Sandbox Delivery](https://github.com/orgs/Ali-Sample/projects/1) project:
one issue per change, placed on a process step.
